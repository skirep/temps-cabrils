# temps-cabrils
Quina roba portart a Cabrils ?

## Android app (wrapper)

Aquest repositori inclou una app Android mínima a `/android` que obre la web de GitHub Pages:
`https://skirep.github.io/temps-cabrils/`

### Build ràpid

```bash
cd android
./gradlew assembleDebug
```

L'APK de debug es genera a:
`android/app/build/outputs/apk/debug/app-debug.apk`
